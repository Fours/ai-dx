## Improvements

### 1. Claude attribution turned off everywhere
- I set `"attribution": { "commit": "", "pr": "" }` and `"includeCoAuthoredBy": false` in `~/.claude/settings.json`. `includeCoAuthoredBy` is the name older Claude Code versions use.

### 2. Global `~/.claude/CLAUDE.md`
- **About me:** my background, the roles I'm targeting and my usual stack.
- **Git rules:**
  - No attribution in commits or PRs.
  - Commit straight to `main`.
  - Only commit when I ask.
- **"Set it up like the portfolio":** describes the S3/CloudFront deploy and the lazy-loaded PostHog setup.

### 3. User-level skills in `~/.claude/skills/`
Each skill copies from my existing code instead of keeping its own copy.

| Skill | What it does |
|---|---|
| `/add-posthog` | Adds lazy-loaded PostHog, copied from the portfolio. |
| `/add-s3-deploy [prefix]` | Adds `npm run deploy` to S3 and CloudFront, plus a checklist of AWS console steps. It notes that one shared deployer IAM user covers the whole bucket, so each new site only adds its CloudFront distribution to that user's cache-clearing (`cloudfront:CreateInvalidation`) permission. |
| `/mobile-gate [message]` | Adds a "not available on mobile" screen for desktop-only apps, based on the solar-system-explorer and archery-game versions. |
| `/next-task [T#]` | Plans, implements, commits, pushes and watches CI for the next task in `docs/milestone-N.md`, based on the rate-limiter workflow. |

### 5. Daily job search rebuilt
**Problems found:**
- About a third of runs saved nothing, mostly because they stopped at permission prompts while nobody was there.
- 40% of jobs came from We Work Remotely, even though the skill said to avoid it.
- Many jobs were poor fits: staffing agencies, companies outside the US, and Vue or data roles.
- The skill file was in the wrong place, so it was never registered as a skill.

**Fixes:**
- Moved the skill to `job-search/SKILL.md`.
- Added `scripts/fetch_jobs.py`, which uses only Python's standard library. It pulls from:
  - the Greenhouse, Ashby and Lever boards of companies on my watchlist
  - RemoteOK and Himalayas
- Added a title filter that keeps AI-era titles such as Product Engineer, AI Product Engineer, Design Engineer, Applied AI and Founding Engineer. It drops Staff, management, data/ML, mobile, contract roles, AI-training gigs and staffing agencies.
- Jobs are now ranked by fit instead of filling a fixed count of 15.
- Added a permission allowlist in `job-search/.claude/settings.local.json` so scheduled runs don't stop at permission prompts.
