## Improvements

### 1. Push whenever I ask for a commit
`~/.claude/CLAUDE.md`, Git section: when I ask for a commit, or run a skill that commits, Claude also pushes if the branch has an upstream. It skips the push only if I say "commit only" or "don't push".

### 2. Tabernacle commit rules fixed
- `tabernacle/AGENTS.md`: "Commit at logical stopping points" is now "Commit only when Kyle asks, or as a step of `/run-plan` after he approves the plan". The push rule now matches the global one.
- `tabernacle/.claude/skills/run-plan/SKILL.md`: the sub-agent instruction to add the attribution line is replaced with "Never add an attribution line".

### 3. Cold reader flags compressed lines
`cold-reader-prompt.md` in both `cozy/` and `litrpg/` (`.claude/skills/draft-chapter/`) has a new category for lines compressed so far that the reader has to work out what they mean. It gives four lines I flagged as examples, such as "There was no outside in it".

### 4. Job search covers more titles
- `job-search/scripts/fetch_jobs.py` now also keeps these titles: Growth Engineer, UI Engineer, Creative Technologist or Developer, Design Technologist, Graphics Engineer, WebGL, Developer Experience and DX Engineer. Staff roles are still excluded.
- `HIMALAYAS_QUERIES` adds "design engineer" and "growth engineer".
- I tested the filter on sample titles.

### 5. Out-of-date context updated
- `~/.claude/CLAUDE.md`:
  - "About me" now mentions the three YouTube channels and the two book series.
  - "Other user-level skills" lists `/update-dashboard` and its nightly scheduled task.
- `ai-dx/AGENTS.md`:
  - Removed "This folder isn't a git repo yet".
  - Added `update-dashboard` and the `update-project-dashboard` scheduled task.
  - Noted the project skills and the cozy/litrpg fork.

### 6. Book repos keep their skills in sync
`cozy/AGENTS.md` and `litrpg/AGENTS.md` now say that the chapter skills are a fork shared with the other repo. When a shared mechanism changes (the cold reader, `used-details.md`, `/canon`), Claude says so and offers to port the change.
